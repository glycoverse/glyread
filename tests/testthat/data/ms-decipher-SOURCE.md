# Original MS-Decipher O-Search result

`ms-decipher-O_Search_15glycans.xlsx` is a byte-for-byte copy of the public
original `O_Search_15glycans.xlsx` deposited in JPST001912. It is not a mock,
reformatted export, or reconstructed spreadsheet. All four original worksheets
(Parameter, PSM, Peptide, Protein) are retained. The Parameter sheet identifies
MS-Decipher Beta(v2020.03.18). This evidence validates the legacy O-Search report
schema, not newer O-Search-Pattern exports.

The original PSM sheet has 2642 rows and 24 columns, all TARGET. It provides
peptide-level total glycan compositions but no quantified abundance or
localized glycosylation sites. The three sample PSM counts are 988, 862 and 792;
after presence aggregation there are 222 unique peptide/protein-group/composition
features, detected 190, 168 and 174 times by sample. No cell values were changed.
